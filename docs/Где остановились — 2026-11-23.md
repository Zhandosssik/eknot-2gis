## Цель проекта

Учебный проект для практики: собрать сведения о жилых домах Астаны,
включая количество квартир, и выгружать их в Excel и CSV.
Нужен автоматический сбор по городу без ручного открытия Firefox.
Krisha.kz пока отложена по просьбе пользователя.

## Какие столбцы нужны пользователю

1. ID объекта.
2. Этажность.
3. Материал стен.
4. Количество подъездов.
5. Название.
6. Адрес.
7. Район.
8. Долгота.
9. Широта.
10. Назначение здания.
11. Рейтинг.
12. Количество отзывов.
13. Количество квартир.
14. Количество лифтов.
15. Год постройки.

ID в XLSX сохраняется как текст, чтобы Excel не превращал его в `7E+16`.
Рейтинг записывается числом, чтобы `4.3` не становилось датой.
CSV использует UTF-8 с BOM, разделитель `;` и десятичную запятую.
Перед ID в CSV добавляется апостроф для защиты длинного номера.
Для открытия в Excel предпочтителен XLSX: CSV не хранит типы ячеек.

## Текущее устройство

Локальный сервис на Python, FastAPI и SQLite.
Сбор через официальный API 2ГИС восстановлен после временного удаления.
Пользователь снова добавил ключ в `.env`; последний реальный запрос подтвердил,
что ключ работает. Не выводить ключ в чат, логи или Git.

Основные файлы:

- `app/main.py` — методы сервиса и страница `/docs`.
- `app/twogis.py` — автоматический сбор через API, лимиты и пагинация.
- `app/db.py` — SQLite, задания, объекты и история ответов.
- `app/settings.py` — загрузка `.env`.
- `app/public_pages.py` — дополнительная проверка публичных HTML-карточек.
- `app/public_export.py` — таблица из 15 столбцов и экспорт CSV/XLSX.
- `scripts/probe_city_access.py` — ограниченная проверка API: три запроса.

Старые результаты экспериментов остаются в `data/`.
Исторические документы могут описывать временное отключение API —
актуальное решение пользователя: использовать API для автоматического сбора.

## Последняя реальная проверка официального API

После повторного добавления ключа выполнены три запроса.
Все вернули HTTP 200 и `meta.code=200`.

### Количество квартир

Метод `/3.0/items/byid`, проверенные ID:

- Айналайын — `70030076177928867`.
- Арлан — `70030076180207546`.
- Atlant — `70030076191027893`.

Явно запрошено `items.structure_info.apartments_count`, а также этажность,
подъезды, лифты и год постройки. Числовые строительные характеристики
не возвращены. Для трёх зданий пришло `has_apartments_info=true`.
Это только признак наличия информации, его нельзя считать числом квартир.

Документация указывает, что `apartments_count` требует дополнительных прав
ключа. Права в кабинете не проверены; отсутствие поля в ответе само по себе
не доказывает, что причина исключительно в правах, а не в наличии данных.

### Выдача по Астане

Метод `/3.0/items`, параметры: `city_id=9570771978420226`,
`type=building`, без текстового запроса.

API сообщил `total=69310`. Проверены первые две страницы по 10 объектов;
ID на страницах различаются. Это здания и сооружения разных назначений,
а не 69 310 жилых домов.

Полный обход всех страниц и полнота охвата города не подтверждены.
Массовый сбор не выполнен. Существуют лимиты запросов, сохранение страницы
и продолжение задания; полноценный результат «вся Астана» пока не достигнут.
Пагинация сама по себе не гарантирует полноту реестра.

Исходные ответы без ключа:
`data/2gis-city-probe-2026-11-22T20-41-24.877099+00-00.json`.
Дата в имени файла — UTC; местная дата проверки — 23 ноября.

## Запуск и проверка

В CMD:

```cmd
cd /d D:\Eknot
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Страница управления: http://127.0.0.1:8000/docs

Автоматический сбор: `POST /api/2gis/jobs`.
Пустой `query` убирает фильтр по названию.
Задания: `GET /api/jobs`.
Продолжение: `POST /api/jobs/{job_id}/resume`.
База API: `/api/export?format=xlsx` или `/api/export?format=csv`.
Проверки страниц: `/api/2gis/public-pages/check` и
`/api/2gis/public-pages/export?format=xlsx` (или `csv`).

```cmd
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Последний полный запуск после восстановления API: 20 тестов успешно.
Они проверяют логику с подменёнными ответами, а не права реального ключа.
Реальные три запроса выполнены отдельно скриптом `probe_city_access.py`.
