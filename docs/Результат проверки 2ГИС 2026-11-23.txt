Повторная проверка получения характеристик домов из 2ГИС
Дата: 23 ноября 2026 года (Asia/Qyzylorda).

Результат: частичный успех.

1. Официальный API
Выполнено шесть запросов с существующим локальным ключом. Контрольный
запрос вернул 10 зданий. Отдельно проверены items.floors, дочерние поля
items.structure_info, родительское поле items.structure_info, сведения
о входах и квартирах, а также поиск Айналайын через /items.
Ответы HTTP 200, meta.code 200; этажность, материал, количество квартир,
подъездов, лифтов и год постройки не возвращены.
Для Айналайын возвращён has_apartments_info=true, но это только признак
наличия информации, а не число квартир.
Документация отмечает необходимость дополнительных прав ключа для этих
характеристик. Права ключа в кабинете не проверялись; точную причину
отсутствия каждого поля по ответу установить нельзя.
https://docs.2gis.com/en/api/search/places/reference/3.0/items/byid

2. Публичные страницы
Скрипт сделал три прямых HTTP-запроса к публичным карточкам. Все вернули
HTTP 200. Из текста HTML (без script/style) автоматически извлечены:

Айналайын — Кайым Мухамедханов, 19: 10 этажей, кирпич, 4 подъезда.
https://2gis.kz/astana/geo/70030076177928867
Арлан — Бердибек Сокпакбаев, 5: 10 этажей, кирпич, 4 подъезда.
https://2gis.kz/astana/geo/70030076180207546
Atlant — Сарайшык, 4: 21 этаж, монолит, 7 подъездов.
https://2gis.kz/astana/geo/70030076191027893

Значения относятся к указанным карточкам зданий; переносить их на все
корпуса одноимённых ЖК нельзя. Число квартир, лифтов и год постройки
в рамках проверки не получены. Полный обход города не выполнялся.
Это экспериментальный скрипт для трёх карточек, а не готовый универсальный
сборщик. В основную базу и API сервиса новые характеристики не добавлены.

3. Материалы
Повторяемая проверка API: scripts/recheck_2gis_characteristics.py
Проверка публичных страниц: scripts/check_2gis_public_pages.py

data/2gis-recheck-2026-11-22T19-38-15.867547+00-00.json
Тексты карточек, извлечённые значения и фрагменты доказательств:

Временные метки файлов указаны в UTC; дата проверки по часовому поясу
пользователя — 23 ноября. Предыдущие результаты сохранены.

Формулировка для дневника практики
Проведена повторная проверка получения строительных характеристик домов
Астаны из 2ГИС. Через официальный API с текущим ключом получить требуемые
поля не удалось. Разработан и проверен экспериментальный скрипт извлечения
данных из публичных HTML-карточек: для трёх зданий получены этажность,
материал стен и количество подъездов. Сохранены результаты запросов и
подтверждающие фрагменты страниц. Получение количества квартир, лифтов
и года постройки остаётся нерешённой задачей.
