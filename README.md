# Eknot — сбор данных о недвижимости

Локальный сервис для сбора данных о жилых комплексах Астаны и Алматы с Krisha.kz
и Korter.kz, а также о зданиях Астаны из 2ГИС. Для 2ГИС доступны проверка
публичных карточек и автоматический сбор через официальный API с ключом.

## Запуск в CMD

```cmd
cd /d D:\Eknot
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Для первоначальной установки: `python -m venv .venv`, затем
`.venv\Scripts\python.exe -m pip install -r requirements.txt`.

Откройте http://127.0.0.1:8000/docs. Оставьте окно сервера открытым.
После изменения кода остановите сервер Ctrl+C и запустите снова.

## Жилые комплексы Krisha.kz

Откройте [таблицу ЖК](http://127.0.0.1:8000/krisha) и выберите Астану или Алматы.
В режиме «По районам» Eknot сохраняет список ЖК из каталога выбранного города,
затем загружает карточки по районам. В Астане первыми идут Нура и Есильский.
Остальные районы Астаны и районы Алматы идут по алфавиту, ЖК без района — в конце.
После завершения района задание останавливается. Чтобы перейти дальше, нажмите «Начать следующий район».
Уже сохранённые карточки используются повторно, если их район совпадает с каталогом.
Кнопка «Продолжить» возобновляет просмотр каталога или обработку карточек с сохранённого места.
Чтобы изменить лимиты существующего задания, задайте новые значения, отметьте
«Применить эти лимиты к продолжению задания» и нажмите «Продолжить» у нужного задания.
Для короткой проверки карточек выберите «По страницам», 1 страницу и 5 запросов.
В таблице можно искать по названию или адресу, выбирать район и открывать характеристики ЖК.
Район выделяется из адреса Krisha.kz. Список районов показывает количество уже собранных ЖК.
Кнопки «Скачать Excel» и «CSV» выгружают сохранённые карточки выбранного города и района.

## Жилые комплексы Korter.kz

Откройте [таблицу Korter.kz](http://127.0.0.1:8000/korter) или выберите Korter.kz
в меню над таблицей Krisha.kz. Выберите Астану или Алматы, режим и лимиты,
затем нажмите «Запустить сбор». В режиме «По районам» сначала сохраняется
список ЖК. После каждого района следующий можно запустить отдельной кнопкой.
Если достигнут лимит или произошёл сбой, кнопка «Продолжить» возобновляет задание.

Сервис обрабатывает публичную выдачу выбранного каталога Korter.kz. В ней могут
быть ЖК пригородов. Число квартир сохраняется в формулировке источника, включая
пометки об очереди. По сохранённым карточкам доступны поиск, фильтр по району
и выгрузки Excel, CSV и JSON.

## Публичные карточки 2ГИС

В разделе «Проверка страниц 2ГИС» откройте
`POST /api/2gis/public-pages/check` → Try it out → Execute.
Можно оставить три дома по умолчанию или указать до трёх числовых ID из
ссылок вида `https://2gis.kz/astana/geo/ID`.

Собираются название, адрес, район и город, этажность, материал стен,
число подъездов, назначение, рейтинг и число отзывов — если найдены в карточке.
Координаты извлекаются из параметра center в метатеге og:image самой страницы
без обращения к сервису изображений: это центр карты карточки, не кадастровая
точка. Количество квартир, лифтов и год постройки извлекаются только при наличии
явных подписей; отсутствие значений не заменяется догадками.
Пустое значение означает, что поле не найдено, а не ноль.
Это характеристики конкретного здания, не всех корпусов одноимённого ЖК.

Скачать последнюю проверку:

- Excel: http://127.0.0.1:8000/api/2gis/public-pages/export?format=xlsx
- CSV: http://127.0.0.1:8000/api/2gis/public-pages/export?format=csv

Ссылки именно на выполненную проверку находятся в поле `downloads` ответа.
Выгрузка содержит 15 столбцов: ID, этажи, материал стен, подъезды, название,
адрес, район, долгота, широта, назначение, рейтинг, отзывы, квартиры, лифты,
год постройки. Источник, дата проверки, доказательства и ошибки остаются
в отчёте проверки. CSV: UTF-8 с BOM, разделитель `;`, десятичная запятая;
перед ID добавлен апостроф для защиты длинного номера от преобразования.
Для Excel предпочтителен XLSX: тип ID — текст, рейтинги и координаты — числа.
CSV сам по себе не хранит типы ячеек; его импорт зависит от настроек программы.

Результаты и тексты страниц сохраняются в `data/2gis-public-*`.
Выгрузка проверки содержит сведения только с публичных карточек.
В пути локальных методов `/api/` обозначает интерфейс нашего сервиса,
а не обращение к API 2ГИС.

## Ограничения

Проверяется до трёх страниц за запуск. Полного обхода Астаны нет.
Разметка сайта может измениться. Ошибка сети, ограничение доступа или
отсутствие поля отображаются в результате; данные не выдумываются.


## Автоматический сбор через API (восстановлен)

В `.env` задайте `TWOGIS_API_KEY=ваш_ключ` и перезапустите сервер.
В `/docs` используйте `POST /api/2gis/jobs`: kind=buildings, query="",
max_pages=2, max_requests=5 для начальной проверки. Пустой query убирает
фильтр по названию. Статус — `/api/jobs`; продолжение —
`POST /api/jobs/{job_id}/resume`. CSV и XLSX — `/api/export?format=csv`
и `/api/export?format=xlsx`.
Запрашиваются количество квартир, этажность, материал, подъезды, лифты,
год постройки, адреса, территории, координаты и статистика отзывов.
Количество квартир требует дополнительных прав ключа.
Сбор всех домов Астаны пока не подтверждён. Поиск по городу с пагинацией
не гарантирует полный реестр; покрытие территории и ограничения выдачи
требуют отдельной проверки. Не все здания являются жилыми.
